# Eggvault
Source code for an embedded ESP32 microcontroller to control an automated chicken door based on a timer, light sensor and physical buttons.
The project included a hardware concept including an electric motor, a pulley mechanism, a user interface consisting of buttons and a screen and a housing design.
Also a custom PCB was designed to connect the microcontroller with all necessary components.
