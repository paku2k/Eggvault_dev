# Eggvault - automatic chicken door
The automatic chicken door is responsible for automatically opening and closing the hen-house depending on:
- a programmed predefined time
- a nighttime-detection depending on the light-level of the environment
- a combination of the above
- user input through buttons

## Software
This project was designed around an embedded ESP32 microcontroller.

The code was mainly written in C and C++ utilizing several libraries for controlling different low-level functions of the ESP32.
Special focus was geared towards battery consumption to be able to operate the chicken door up to 2 years on 4 AA batteries.
## Hardware and Electronics
The project also included a hardware concept including an electric motor, a pulley mechanism, a user interface consisting of buttons and a screen and a housing design.

A custom PCB was designed to connect the microcontroller with all electronic components.
